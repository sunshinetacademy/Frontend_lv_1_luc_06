ما هو Box Model؟ 📦

في CSS، كل عنصر في الصفحة يُعامل كـ صندوق (Box)!

هذا الصندوق يتكون من 4 أجزاء من الداخل للخارج:

📊 الرسم التوضيحي لـ Box Model

MARGIN (الهامش الخارجي)
BORDER (الحد/الإطار)
PADDING (الحشوة الداخلية)
CONTENT
(المحتوى)
💡 تشبيه بسيط:
تخيل موبايل في علبته:
📱 Content = الموبايل نفسه
🛡️ Padding = الإسفنجة حول الموبايل
📦 Border = العلبة الكرتون
🌫️ Margin = المسافة بين علبتك وعلبة أخرى على الرف

🔍 شرح كل جزء بالتفصيل:

الجزءالوصفالخاصية
Content المحتوى الفعلي (نص، صورة...) width, height
Padding المسافة داخل العنصر (بين المحتوى والحد) padding
Border الحد/الإطار حول العنصر border
Margin المسافة خارج العنصر (بينه وبين العناصر الأخرى) margin

1️⃣ Content — المحتوى (Width & Height)

نتحكم في حجم المحتوى بـ width (العرض) و height (الارتفاع).

width-height.css
.box {
    width: 200px;
    height: 100px;
    background-color: #3498db;
}
200px × 100px
💡 الوحدات الشائعة:
  • px = بكسل (الأشهر)
  • % = نسبة مئوية من العنصر الأب
  • auto = تلقائي (حسب المحتوى)

2️⃣ Padding — الحشوة الداخلية

Padding = المسافة داخل العنصر بين المحتوى والحد.

يُستخدم لإعطاء "مساحة تنفس" للمحتوى.

🎯 طرق كتابة Padding:

padding.css
/* طريقة 1: padding واحد لكل الجوانب */
.box1 {
    padding: 20px;
}

/* طريقة 2: أعلى/أسفل | يمين/يسار */
.box2 {
    padding: 20px 40px;
}

/* طريقة 3: أعلى | يمين/يسار | أسفل */
.box3 {
    padding: 10px 20px 30px;
}

/* طريقة 4: أعلى | يمين | أسفل | يسار (اتجاه الساعة ⏰) */
.box4 {
    padding: 10px 20px 30px 40px;
}

/* طريقة 5: كل جانب منفصل */
.box5 {
    padding-top: 10px;
    padding-right: 20px;
    padding-bottom: 30px;
    padding-left: 40px;
}

❌ بدون Padding

نص ملتصق بالحواف

✅ مع Padding: 20px

نص مريح ومتباعد
💡 القاعدة البسيطة:
padding: 20px → كل الجوانب 20px
padding: 20px 40px → أعلى/أسفل 20px، يمين/يسار 40px

3️⃣ Border — الحد/الإطار

Border = الخط/الإطار حول العنصر.

نحتاج 3 أشياء: السُمك، النوع، اللون

border.css
/* الطريقة المختصرة (الأشهر) */
.box {
    border: 3px solid #e74c3c;
    /*      ↑     ↑      ↑
            سُمك  نوع   لون  */
}

/* أو كل خاصية منفصلة */
.box2 {
    border-width: 3px;
    border-style: solid;
    border-color: #e74c3c;
}

4️⃣ Margin — الهامش الخارجي

Margin = المسافة خارج العنصر (المسافة بينه وبين العناصر الأخرى).

نفس طريقة كتابة padding بالظبط!

margin.css
/* margin واحد لكل الجوانب */
.box {
    margin: 20px;
}

/* أعلى/أسفل | يمين/يسار */
.box2 {
    margin: 30px 50px;
}

/* توسيط العنصر أفقياً (مهم جداً!) */
.centered {
    margin: 0 auto;
    width: 300px; /* لازم يكون له عرض محدد */
}

⚠️ الفرق بين Padding و Margin:
Padding = داخل العنصر (يزيد حجمه، يأخذ لون الخلفية)
Margin = خارج العنصر (لا يأخذ لون الخلفية، شفاف)

box-sizing: border-box — الحل السحري! ✨

المشكلة: عندما نضع width: 200px + padding: 20px + border: 5px

الحجم النهائي = 200 + (20×2) + (5×2) = 250px 😱

⚠️ هذا يسبب مشاكل كثيرة! خصوصاً في التصميمات المتجاوبة.

🎯 الحل: box-sizing: border-box

box-sizing.css
/* نضعها في بداية ملف CSS */
* {
    box-sizing: border-box;
}

/* الآن: width = الحجم الكلي الفعلي شاملاً padding و border */
.box {
    width: 200px;
    padding: 20px;
    border: 5px solid #333;
    /* الحجم النهائي = 200px فقط! ✅ */
}
💡 نصيحة ذهبية: ضع دائماً في بداية ملف CSS:
* { box-sizing: border-box; }
هذا سيوفر عليك الكثير من المشاكل!

✅ ما تعلمناه اليوم

  • Box Model = 4 أجزاء: Content, Padding, Border, Margin
  • Padding = مسافة داخلية (داخل العنصر)
  • Margin = مسافة خارجية (خارج العنصر)
  • Border = الحد/الإطار حول العنصر
  • border-radius للزوايا المدورة
  • box-sizing: border-box — الحل السحري!
  • margin: 0 auto للتوسيط الأفقي
  • بنينا بطاقة منتج احترافية كاملة! 🛍️

📝 الواجب — 5 مسائل

المسألة 1: تجارب Box Model

المطلوب: أنشئ 4 صناديق ملونة، كل واحد يوضح جزء من Box Model:

  • صندوق 1: padding كبير (30px)
  • صندوق 2: border سميك (10px) ملون
  • صندوق 3: margin كبير (40px)
  • صندوق 4: يجمع الثلاثة معاً

المسألة 2: بطاقات منتجات

المطلوب: أنشئ 3 بطاقات منتجات بجانب بعض:

  • كل بطاقة لها: صورة (emoji)، عنوان، سعر، وصف، زر
  • استخدم padding مناسب
  • استخدم border-radius للزوايا المدورة
  • استخدم margin لإبعاد البطاقات عن بعضها

المسألة 3: زر احترافي

المطلوب: صمم 5 أزرار مختلفة الأشكال:

  • زر بزوايا حادة
  • زر بزوايا مدورة قليلاً (5px)
  • زر بزوايا مدورة جداً (25px)
  • زر دائري تماماً
  • زر بحد ملون وخلفية شفافة

المسألة 4: التوسيط

المطلوب: أنشئ صندوق ووسطه في الصفحة بطريقتين:

  • الطريقة 1: margin: 0 auto
  • اجعل الصندوق له: عرض 400px، padding 30px، border 3px، border-radius 15px

المسألة 5: 🏆 مشروع كامل — متجر بسيط

المطلوب: ابنِ صفحة متجر بسيطة تحتوي على:

  • عنوان رئيسي في الأعلى (مع padding و border-bottom)
  • 3 بطاقات منتجات على الأقل
  • كل بطاقة لها:
    • صورة (emoji أو لون خلفية)
    • اسم المنتج
    • السعر
    • وصف قصير
    • زر "أضف للسلة"
  • استخدم box-sizing: border-box
  • استخدم padding و margin و border-radius بشكل احترافي
  • اجعل البطاقات موسطة في الصفحة
💡 نصيحة: افتح Developer Tools في المتصفح (F12) واذهب لتبويب "Elements" — ستجد رسم Box Model لأي عنصر تختاره!
