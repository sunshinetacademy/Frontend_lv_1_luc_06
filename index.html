🎨
ما هو CSS؟

📖 التعريف

CSS = Cascading Style Sheets = أوراق الأنماط المتتالية.

CSS هي اللغة اللي بنستخدمها عشان نصمم وننسق صفحات HTML. بتتحكم في:

• الألوان والخطوط

• المسافات والأحجام

• ترتيب العناصر (Layout)

• الحركات والتأثيرات

• التجاوب مع الشاشات المختلفة

💡 تشبيه من الحياة

  • HTML = هيكل البيت (الأعمدة، الجدران، الغرف)
  • CSS = الدهان، الديكور، الأثاث، الإضاءة
  • HTML بدون CSS = بيت بدون دهان ولا أثاث — هيكل بس
  • HTML مع CSS = بيت جميل ومنسق وجاهز للسكن

📐 شكل قاعدة CSS

أي كود CSS بيتكون من جزئين أساسيين: Selector و Declaration Block

CSS — الشكل الأساسي 
selector {
    property: value;
    property: value;
}

/* مثال حقيقي */
h1 {
    color: #4A7C59;
    font-size: 32px;
    text-align: center;
}

🔍 تشريح قاعدة CSS

الجزء المعنى مثال
Selector العنصر اللي عايز تغيره h1, .class, #id
Property الخاصية اللي عايز تغيرها color, font-size
Value القيمة الجديدة red, 20px
Declaration property + value + ; color: red;

3 طرق لإضافة CSS

📖 الطرق الثلاثة

في 3 طرق تقدر تضيف بيهم CSS لصفحة HTML. كل طريقة ليها استخداماتها ومميزاتها.

📌

Inline CSS

جوه الـ HTML مباشرة بـ style attribute

✓ سريع للتجربة
✗ صعب الصيانة
✗ مفيش إعادة استخدام
⚠️ تجنبه قدر الإمكان
📄

Internal CSS

جوه <style> في الـ <head>

✓ منظم أكتر
✓ لصفحة واحدة
✗ مش بيتشارك بين الصفحات
👍 كويس لصفحة واحدة
🔗

External CSS

ملف .css منفصل بيتربط بـ <link>

✓ إعادة استخدام
✓ سهل الصيانة
✓ Cache في المتصفح
✗ ملف إضافي
⭐ الأفضل — المحترفين بيستخدموه

🔹 الطريقة الأولى: Inline CSS

بتكتب CSS جوه الـ HTML مباشرة باستخدام attribute style

HTML — Inline CSS 
<h1 style="color: #4A7C59; font-size: 32px; text-align: center;">
    مرحباً بيك
</h1>

<p style="color: #78350F; line-height: 1.8;">
    دي فقرة نصية
</p>

⚠️ ليه Inline CSS مش مستحسن؟

1. فوضى: الكود بيبقى مليان attributes في كل عنصر.

2. إعادة استخدام: لو عايز تغير اللون في 100 عنصر، لازم تغيرهم واحد واحد!

3. صيانة: صعب تعدل على الموقع بعدين.

🔹 الطريقة الثانية: Internal CSS

بتكتب CSS جوه <style> في الـ <head> من الصفحة.

HTML — Internal CSS 
<head>
    <meta charset="UTF-8">
    <title>صفحتي</title>
    
    <style>
        h1 {
            color: #4A7C59;
            font-size: 32px;
            text-align: center;
        }
        
        p {
            color: #78350F;
            line-height: 1.8;
        }
    </style>
</head>
<body>
    <h1>مرحباً بيك</h1>
    <p>دي فقرة نصية</p>
</body>

🔹 الطريقة الثالثة: External CSS (الأفضل)

بتكتب CSS في ملف منفصل .css وبتربطه بالصفحة بـ <link>

style.css — ملف CSS منفصل 
/* ملف: css/style.css */

h1 {
    color: #4A7C59;
    font-size: 32px;
    text-align: center;
}

p {
    color: #78350F;
    line-height: 1.8;
}
HTML — ربط الملف 
<head>
    <meta charset="UTF-8">
    <title>صفحتي</title>
    
    <!-- ربط ملف CSS -->
    <link rel="stylesheet" href="css/style.css">
</head>
<body>
    <h1>مرحباً بيك</h1>
    <p>دي فقرة نصية</p>
</body>

✅ ليه External CSS هو الأفضل؟

1. فصل الاهتمامات: HTML للهيكل، CSS للتصميم.

2. إعادة استخدام: ملف CSS واحد لكل الموقع.

3. صيانة سهلة: غير اللون في مكان واحد، يتغير في كل الموقع.

4. Cache: المتصفح بيحفظ الملف، فبيحمل مرة واحدة بس.

📊 مقارنة سريعة

الطريقة الاستخدام التوصية
Inline تجربة سريعة / تعديل صغير ❌ تجنبها
Internal صفحة واحدة مستقلة 👍 مقبولة
External أي مشروع حقيقي ⭐ الأفضل دائماً

🎯
CSS Selectors — الاختيار

📖 ما هي Selectors؟

الـ Selector هو اللي بيحدد إيه العنصر (أو العناصر) اللي عايز تطبق عليه التصميم. زي ما تختار أوضة في البيت عشان تدهنها.

🔹 1. Element Selector — اختيار العنصر

بتختار العنصر باسمه. بيأثر على كل العناصر من النوع ده في الصفحة.

p {
  color: blue;
}
paragraph 1 (أزرق)
paragraph 2 (أزرق)
paragraph 3 (أزرق)
CSS — Element Selector 
/* كل h1 في الصفحة */
h1 {
    color: #4A7C59;
    font-size: 32px;
}

/* كل p في الصفحة */
p {
    color: #4A3728;
    line-height: 1.8;
}

🔹 2. Class Selector — اختيار الفئة

بتختار العناصر اللي عندها class معين. بتستخدم . (نقطة) قبل اسم الـ class.

مهم: ممكن تستخدم نفس الـ class في عناصر كتيرة.

.highlight {
  background: yellow;
}
paragraph عادي
paragraph مميز (أصفر)
paragraph عادي
paragraph مميز (أصفر)
HTML + CSS — Class Selector 
/* CSS */
.highlight {
    background-color: yellow;
    padding: 5px;
}

.error {
    color: red;
    font-weight: bold;
}
HTML — استخدام Class 
<p>فقرة عادية</p>
<p class="highlight">فقرة مميزة</p>
<p class="error">رسالة خطأ</p>

<!-- ممكن نستخدم أكتر من class -->
<p class="highlight error">مميز وخطأ</p>

🔹 3. ID Selector — اختيار المعرّف

بتختار عنصر واحد محدد بـ ID. بتستخدم # قبل اسم الـ ID.

مهم: الـ ID لازم يكون فريد — مرة واحدة بس في الصفحة.

#main-title {
  color: green;
}
العنوان الرئيسي (أخضر)
عنوان تاني عادي
عنوان تالت عادي
HTML + CSS — ID Selector 
/* CSS */
#main-title {
    color: #4A7C59;
    font-size: 48px;
}

/* HTML */
<h1 id="main-title">العنوان الرئيسي</h1>
<h2>عنوان تاني</h2>

🚨 Class vs ID — الفرق المهم

Class: ممكن يتكرر في أكتر من عنصر (زي "طالب" في فصل — كتير).

ID: فريد — عنصر واحد بس (زي "رقم القومي" — واحد بس).

القاعدة: استخدم Class في 90% من الحالات. استخدم ID بس لو فعلاً محتاج عنصر واحد محدد.

🔹 4. Universal Selector — الاختيار الشامل

بيختار كل العناصر في الصفحة. بيستخدم *

CSS — Universal Selector 
/* تطبيق على كل العناصر */
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

🔹 5. Grouping Selector — اختيار المجموعة

بتطبق نفس التصميم على أكتر من selector باستخدام الفاصلة ,

CSS — Grouping Selector 
/* نفس التنسيق لـ h1, h2, h3 */
h1, h2, h3 {
    font-family: 'Cairo', sans-serif;
    color: #4A7C59;
}

/* نفس التنسيق لـ class مختلفة */
.btn, .button, .link-btn {
    padding: 10px 20px;
    border-radius: 8px;
}

🔹 6. Descendant Selector — اختيار الأحفاد

بتختار عنصر جوه عنصر تاني. باستخدام المسافة.

CSS — Descendant Selector 
/* كل p جوا article */
article p {
    color: #4A3728;
    line-height: 1.8;
}

/* كل a جوا nav */
nav a {
    color: white;
    text-decoration: none;
}
HTML — مثال 
<article>
    <p>ده هيأثر عليه (جوا article)</p>
    <div>
        <p>ده كمان (جوا article جوا div)</p>
    </div>
</article>

<p>ده مش هيأثر عليه (مش جوا article)</p>

📊 ملخص الـ Selectors

Selector الصيغة مثال الاستخدام
Element tag p { } كل عناصر من نوع معين
Class .name .btn { } عناصر ليها نفس الـ class
ID #name #header { } عنصر واحد فريد
Universal * * { } كل العناصر
Grouping A, B h1, h2 { } أكتر من selector
Descendant A B nav a { } B جوا A

Specificity — الأولوية

📖 ما هي Specificity؟

لما يكون عندك أكتر من قاعدة CSS بتأثر على نفس العنصر، مين اللي بياخد الأولوية؟ هنا بييجي دور Specificity.

💡 تشبيه من الحياة

تخيل إن أب وأم وجد بيأمروا طفل بحاجات مختلفة. مين اللي الطفل هيسمع؟

  • Inline CSS = الأب (الأقوى — 1000)
  • ID = الأم (قوي — 100)
  • Class = الجد (متوسط — 10)
  • Element = صديق (ضعيف — 1)

CSS — مثال Specificity 
/* Specificity: 0-0-0-1 */
p {
    color: blue;
}

/* Specificity: 0-0-1-0 */
.text {
    color: green;
}

/* Specificity: 0-1-0-0 */
#main {
    color: red;
}

/* لو العنصر: <p id="main" class="text"> */
/* اللون هيكون RED — لأن ID أعلى specificity */

⚠️ نصيحة مهمة

متستخدمش !important إلا في حالات نادرة جداً. لو محتاجه، ده غالباً معناه إن في مشكلة في تنظيم الـ CSS بتاعك.

🔹 3. RGB Colors — الأحمر والأخضر والأزرق

كل لون من 0 لـ 255. rgb(red, green, blue)

CSS — RGB 
h1 { color: rgb(74, 124, 89); } /* أخضر غابي */
p { color: rgb(255, 0, 0); } /* أحمر */
div { background: rgb(0, 0, 0); } /* أسود */

🔹 4. RGBA — RGB مع الشفافية

نفس RGB + قيمة Alpha (شفافية) من 0 لـ 1.

CSS — RGBA 
.overlay {
    background: rgba(0, 0, 0, 0.5); /* أسود شفاف 50% */
}

.card {
    background: rgba(74, 124, 89, 0.1); /* أخضر شفاف جداً */
}

🔹 5. HSL — Hue, Saturation, Lightness

أسهل طريقة للفهم البشري:

• Hue (0-360): اللون على دائرة الألوان

• Saturation (0%-100%): قوة اللون

• Lightness (0%-100%): إضاءة اللون

CSS — HSL 
h1 { color: hsl(140, 25%, 39%); } /* أخضر غابي */
p { color: hsl(0, 100%, 50%); } /* أحمر */

/* HSLA — مع شفافية */
.overlay {
    background: hsla(0, 0%, 0%, 0.5);
}

✅ أي طريقة أستخدم؟

• HEX: الأكثر شيوعاً — استخدمه في 80% من الحالات.

• RGBA: لما تحتاج شفافية.

• HSL: لما تحتاج تعدل على اللون بسهولة (تفتحه، تغلقه).

CSS — Backgrounds 
/* لون خلفية */
.card {
    background-color: #F5EFE6;
}

.hero {
    background-image: url('images/hero.jpg');
    background-size: cover;
    background-position: center;
    background-repeat: no-repeat;
}

/* Shorthand — كلهم في سطر */
.banner {
    background: #4A7C59 url('bg.jpg') center/cover no-repeat;
}

Units — وحدات القياس

📖 ليه الوحدات مهمة؟

في CSS، أي رقم لازم يكون معاه وحدة قياس. اختيار الوحدة الصح بيأثر على:

• التجاوب (Responsive)

• سهولة الصيانة

• تجربة المستخدم

px
Pixels
وحدة ثابتة — مقاس محدد
%
Percentage
نسبة من العنصر الأب
em
Em
نسبة من حجم خط العنصر الأب
rem
Root Em
نسبة من حجم خط الـ root (html)
vw
Viewport Width
1% من عرض الشاشة
vh
Viewport Height
1% من ارتفاع الشاشة

🔹 1. Pixels (px) — الوحدة الثابتة

أبسط وحدة. 16px = 16 بكسل على الشاشة.

CSS — Pixels 
h1 {
    font-size: 32px;
}

.box {
    width: 300px;
    height: 200px;
}

⚠️ مشكلة px

px مش متجاوب. لو المستخدم غيّر حجم الخط في المتصفح، px مش هيتأثر. كمان على الشاشات المختلفة، نفس الـ px ممكن يظهر بأحجام مختلفة.

🔹 2. Percentage (%) — النسبة المئوية

بتحسب نسبة من العنصر الأب.

CSS — Percentage 
.container {
    width: 100%; /* عرض الأب كامل */
}

.half {
    width: 50%; /* نص عرض الأب */
}

🔹 3. em — نسبة من الأب

1em = حجم خط العنصر الأب.

CSS — em 
body {
    font-size: 16px;
}

p {
    font-size: 1.5em; /* 1.5 × 16 = 24px */
    margin-bottom: 1em; /* 24px (حسب حجم الخط الحالي) */
}

🔹 4. rem — نسبة من الـ Root

1rem = حجم خط عنصر <html> (عادة 16px).

rem أفضل من em لأنه ثابت ومش بيتأثر بالعنصر الأب.

CSS — rem 
html {
    font-size: 16px; /* 1rem = 16px */
}

h1 {
    font-size: 2rem; /* 32px */
}

p {
    font-size: 1rem; /* 16px */
    margin-bottom: 1.5rem; /* 24px */
}

✅ ليه rem أفضل؟

• ثابت: 1rem = 16px في كل مكان.

• متجاوب: لو المستخدم غيّر حجم الخط في المتصفح، rem بيتأثر.

• سهل الحساب: 2rem = 32px دايماً.

🔹 5. vw & vh — نسبة من الشاشة

1vw = 1% من عرض الشاشة. 1vh = 1% من ارتفاع الشاشة.

CSS — vw & vh 
.hero {
    height: 100vh; /* ارتفاع الشاشة كامل */
    width: 100vw; /* عرض الشاشة كامل */
}

.title {
    font-size: 5vw; /* حجم الخط 5% من عرض الشاشة */
}

📊 متى نستخدم كل وحدة؟

الوحدة نوع الاستخدام
px ثابت Borders, shadows, تفاصيل صغيرة
% نسبي Widths, Layouts
em نسبي من الأب Padding, Margin جوه عنصر
rem نسبي من root Font sizes, Spacings ⭐
vw نسبي من الشاشة Responsive typography
vh نسبي من الشاشة Full-height sections

📌 ملخص المحاضرة

  • CSS = Cascading Style Sheets — للتحكم في التصميم
  • 3 طرق لإضافة CSS: Inline (❌)، Internal (👍)، External (⭐ الأفضل)
  • قاعدة CSS = Selector + Declaration Block
  • Selectors: Element, Class (.)، ID (#)، Universal (*)، Grouping (,)، Descendant ( )
  • Class = يتكرر، ID = فريد
  • Specificity: Inline (1000) > ID (100) > Class (10) > Element (1)
  • الألوان: Named, HEX (#RRGGBB)، RGB, RGBA, HSL
  • Backgrounds: color, image, size, position, repeat
  • Units: px (ثابت)، % (نسبي)، em (من الأب)، rem (من root) ⭐، vw/vh (من الشاشة)
  • استخدم External CSS + Class selectors + rem في معظم الحالات

أسئلة اختيار من متعدد

10 أسئلة لاختبار فهمك لمحتوى المحاضرة

سؤال 1

ما معنى CSS؟

  • أ Computer Style Sheets
  • ب Cascading Style Sheets
  • ج Creative Style System
  • د Colorful Style Sheets
سؤال 2

أي طريقة لإضافة CSS هي الأفضل للمشاريع الحقيقية؟

  • أ Inline CSS
  • ب Internal CSS
  • ج External CSS
  • د كلهم بنفس الكفاءة
سؤال 3

ما هو الرمز المستخدم لـ Class Selector؟

  • أ # (hash)
  • ب . (dot)
  • ج * (star)
  • د @ (at)
سؤال 4

ما هو الفرق بين Class و ID؟

  • أ مفيش فرق
  • ب Class فريد، ID يتكرر
  • ج Class يتكرر، ID فريد
  • د Class للنصوص، ID للألوان
سؤال 5

أي selector عنده أعلى Specificity؟

  • أ Element (p)
  • ب Class (.btn)
  • ج ID (#header)
  • د Universal (*)
سؤال 6

ما هو الشكل الصحيح لـ HEX Color؟

  • أ #GGHHII
  • ب #RRGGBB
  • ج RGB(255, 255, 255)
  • د color: #12345
سؤال 7

ما هي وظيفة RGBA؟

  • أ إضافة شفافية للون
  • ب تغيير حجم اللون
  • ج إضافة حركة للون
  • د تغيير اتجاه اللون
سؤال 8

ما هي قيمة background-size اللي بتخلي الصورة تغطي العنصر كله؟

  • أ contain
  • ب cover
  • ج auto
  • د full
سؤال 9

ما هي وحدة rem؟

  • أ نسبة من حجم خط العنصر الأب
  • ب نسبة من حجم خط عنصر html (root)
  • ج وحدة ثابتة زي px
  • د نسبة من عرض الشاشة
سؤال 10

أي وحدة دي بتتأثر بحجم الشاشة؟

  • أ px
  • ب rem
  • ج vw
  • د em

واجبات المحاضرة

5 مسائل تطبيقية متدرجة لتثبيت ما تعلمته

📌 الواجب الأول: تجربة الطرق الثلاثة

ابني صفحة HTML بسيطة وجرب الطرق الثلاثة لـ CSS:

  • Inline: غيّر لون h1 واحد بـ style attribute
  • Internal: حط <style> في head وغيّر لون كل p
  • External: اعمل ملف style.css وربطه بـ <link>
  • احذف الطرق اللي مش محتاجها وسيب External بس

📌 الواجب الثاني: Selectors Practice

ابني صفحة HTML فيها:

  • 3 عناصر h1, h2, h3 — غيّر لونهم بـ Element Selector
  • 4 فقرات — 2 منهم بـ class "highlight" (خلفية صفراء)
  • عنوان واحد بـ ID "main-title" — حجم 48px
  • استخدم Grouping Selector على كل الـ headings
  • استخدم Descendant Selector: كل li جوا ul معين

📌 الواجب الثالث: Color Palette

ابني صفحة "Color Palette" فيها:

  • 5 boxes كل box بلون مختلف
  • استخدم: Named Color, HEX, RGB, RGBA, HSL (واحد لكل نوع)
  • تحت كل box اكتب الكود المستخدم
  • استخدم RGBA لعمل overlay شفاف على صورة

📌 الواجب الرابع: Backgrounds Gallery

ابني صفحة "معرض الخلفيات" فيها:

  • Section بخلفية لونية
  • Section بخلفية صورة (background-image + cover)
  • Section بخلفية صورة + overlay شفاف (RGBA)
  • Card بخلفية pattern (repeat)
  • Hero section بـ 100vh + صورة خلفية + عنوان في النص
